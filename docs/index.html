    About Athena

    A multi-agent AI research scientist, originally built on the OpenAI Agents SDK.

    Athena converts research questions into evidence-grounded research dossiers using an eight-stage agent pipeline for literature review, RAG-based synthesis, research-gap discovery, hypothesis generation, statistical experiment design, citation verification and scientific writing, with deterministic citation guardrails and human-in-the-loop approval.

    PlanPrincipal Investigator sharpens the question, recalls memory, sets scope.
    LiteratureParallel search across arXiv, OpenAlex and Crossref; dedup and curation.
    SynthesisRAG over the corpus; every claim cites a retrieved paper.
    Gap analysisClassifies gaps by type, severity and tractability.
    HypothesesDivergent step (temperature 0.8): falsifiable, scored, ranked.
    ExperimentProtocol with a sample size computed by power analysis.
    CitationsDeterministic, verified bibliography in APA, IEEE, MLA or Nature.
    ReportScientific Writer assembles the dossier; saving it needs your approval.

    Deterministic pipeline

    The order of stages is code, not a model's choice — you cannot synthesise evidence you have not retrieved. The judgement inside each stage is the model's.

    Citation guardrail

    Every paper_id an agent cites is checked against the retrieved corpus. Invented ids are rejected with certainty, and the stage is re-asked with the bad ids named.

    Human in the loop

    Saving the dossier always pauses for approval, and deep sweeps above 30 results pause too. Defer a decision and the run is checkpointed so you can resume it later from History.

    Three memory tiers

    Conversation memory within a run, working memory (the shared research context) and long-term memory that persists across sessions and is recalled at the start of every study.

    Computed, not guessed

    Sample sizes come from a power-analysis tool; other numbers from a sandboxed Python runtime; dataset statistics (Welch's t, Cohen's d, correlations) are computed exactly.

    Document-grounded mode

    Confine a study to your own PDFs: web search is switched off and every stage reads the full source text, quoting its numbers exactly.

    Multi-modal input

    Attach PDFs (parsed locally), figures (vision model), recorded talks (Whisper) and CSV / Excel datasets.

    Cost control

    Every model call is metered by model rate; no new stage starts once the run's spending cap is reached.

    This browser edition

    • Runs entirely in your browser. GitHub Pages only serves static files, so the Python backend is re-implemented in JavaScript. Model calls go straight from your browser to api.openai.com with your own API key; nothing passes through any other server.
    • Your key stays local. It is kept in this browser's session storage (or local storage if you tick “remember”). Never commit an API key to the repository.
    • Offline demo mode. Without a key, deterministic stand-in agents run the full pipeline. Literature search, retrieval, citation verification, power analysis and approvals are all real — only the writing is templated.
    • Storage. Run history, checkpoints, saved dossiers and long-term memory live in IndexedDB, the browser counterpart of the original SQLite databases.
    • Libraries. pdf.js for PDF parsing, Pyodide for the Python analysis sandbox, SheetJS for Excel files and marked + DOMPurify for rendering — each loaded from a CDN only when needed.
